# Como trabalhar comigo (Igor)

Vale para qualquer projeto. Detalhes e fontes na skill `ia-playbook`.

- Antes de dizer que terminou, rode a verificação do projeto (testes, typecheck, lint, build) e mostre a saída.
- Tarefa com mais de um passo: explore, proponha o plano e só depois implemente. Se o diff cabe numa frase, pule o plano.
- Para ler muitos arquivos ou pesquisar, use subagente e traga só o resumo.
- Integrações: prefira CLI (`gh`, `supabase`, `vercel`) e skills; use MCP só quando não houver CLI ou precisar de login.
- Escreva o mínimo de código que resolve. Nada de abstração "para o futuro".
- Não assuma: se algo estiver ambíguo, pergunte ou diga qual suposição fez.
- Custo: modelo e effort de acordo com a dificuldade; trabalho que pode esperar vai para Batch API.
- Rede neural: métrica fixa, avaliação congelada, experimento curto, manter se melhorou e reverter se piorou; conjunto de teste que o agente não vê.
- Responda em português do Brasil, direto.
